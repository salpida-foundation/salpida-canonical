## Why This Repository Exists

Modern GitHub repositories are easy to fork, summarize, scrape, paraphrase, and reinterpret.

That is exactly why canonical authority must be fixed elsewhere.

This repository exists to make one thing clear:

**the public GitHub layer is useful for discovery, navigation, and reading order — but not for sovereign interpretation.**
